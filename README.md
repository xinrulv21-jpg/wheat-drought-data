# Wheat Drought-Tolerance Data
This repository contains genotypic and phenotypic data supporting a study of drought tolerance in spring wheat.
## Files
### Genotype.hmp.zip
This archive contains the genotypic data. Extract the archive before use.
Each row represents one SNP marker. The first 11 columns contain marker-related information, and columns 12 onward contain genotype calls for individual accessions, with accession identifiers as column headers.
SNP coordinates are based on the IWGSC RefSeq v1.0 reference genome.
### Phenotype.xlsx
This workbook contains phenotypic measurements of seven agronomic traits across three environments and two water treatments. It includes six worksheets:
| Worksheet | Year | Location | Water treatment |
| 23DX-W | 2023 | Dingxi | Well-watered (WW) |
| 23DX-D | 2023 | Dingxi | Water stress (WS) |
| 23TW-W | 2023 | Tongwei | Well-watered (WW) |
| 23TW-D | 2023 | Tongwei | Water stress (WS) |
| 24DX-W | 2024 | Dingxi | Well-watered (WW) |
| 24DX-D | 2024 | Dingxi | Water stress (WS) |
DX denotes Dingxi, and TW denotes Tongwei. In worksheet names, W denotes well-watered (WW) conditions, and D denotes water stress (WS) conditions. The WS treatment was rain-fed, relying solely on natural precipitation.
## Phenotypic Variables
| Abbreviation | Trait |
| PH | Plant height |
| SN | Spike number |
| GNS | Grain number per spike |
| TGW | Thousand-grain weight |
| TSS | Total spikelet number per spike |
| GL | Grain length |
| GW | Grain width |
The column-name suffixes `-1` and `-2` indicate field replicates 1 and 2, respectively.
`NA` indicates missing phenotypic data.
