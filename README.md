# Wheat drought-tolerance data
This repository contains genotypic and phenotypic data supporting a study of drought tolerance in spring wheat.
## Files
### Genotype.hmp.zip
This archive contains the genotypic data. Extract the archive before use.
Each row represents one SNP marker. The first 11 columns contain marker-related information, and columns 12 onward contain genotype calls for individual accessions, with accession identifiers as column headers.
SNP coordinates are based on the IWGSC RefSeq v1.0 reference genome.
### Phenotype.xlsx
This workbook contains phenotypic measurements of seven agronomic traits across three environments and two water treatments. It includes six worksheets.
The worksheets 23DX-W and 23DX-D contain data collected at Dingxi in 2023 under well-watered (WW) and water stress (WS) conditions, respectively.
The worksheets 23TW-W and 23TW-D contain data collected at Tongwei in 2023 under WW and WS conditions, respectively.
The worksheets 24DX-W and 24DX-D contain data collected at Dingxi in 2024 under WW and WS conditions, respectively.
DX denotes Dingxi, and TW denotes Tongwei. In worksheet names, W denotes WW conditions, and D denotes WS conditions. The WS treatment was rain-fed, relying solely on natural precipitation.
#### Phenotypic Variables
The seven agronomic traits are plant height (PH), spike number (SN), grain number per spike (GNS), thousand-grain weight (TGW), total spikelet number per spike (TSS), grain length (GL), and grain width (GW).
The column-name suffixes -1 and -2 indicate field replicates 1 and 2, respectively.
NA indicates missing phenotypic data.
